# Python String Logic Practice

This repository contains basic but important string logic problems solved using Python.

These problems focus on strengthening problem-solving skills and understanding of core string concepts.

---

## 📚 Topics Covered

- String immutability
- String slicing and reversing
- Swapping first and last characters
- Counting word occurrences in a sentence
- Sorting words alphabetically
- Conditional string manipulation
- Length-based string operations

---

## 🎯 Purpose

The goal of this repository is to:
- Build strong fundamentals in Python
- Improve logical thinking
- Practice interview-oriented problems
- Strengthen DSA basics

---

## 🛠 Language Used

- Python 3
- Jupyter Notebook (.ipynb)
